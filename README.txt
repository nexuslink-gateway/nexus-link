NEXUS LINK — ARCHIVOS PARA EL REPOSITORIO

1. Sube todos estos archivos juntos a la raíz del repositorio.
2. Conserva sus nombres para que el favicon, los iconos y el manifiesto funcionen.
3. Google puede tardar varios días o semanas en actualizar el icono de sus resultados.
4. El anuncio se solicita al cargar el documento, en la primera oportunidad permitida por el navegador. Los navegadores pueden bloquear ventanas automáticas hasta que exista una interacción.

Archivos:
- index.html: sitio actualizado
- favicon.png: icono para navegador y Google
- apple-touch-icon.png: icono para iPhone/iPad
- icon-192.png e icon-512.png: iconos de aplicación web
- logo-nexus-link.png: logo original extraído del index
- site.webmanifest: identidad de la aplicación web
